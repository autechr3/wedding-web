# Wedding Website — Content-Gathering Checklist

A luxury destination-wedding website consultant's checklist of everything to gather
before launch. Tagged **[Required]** (needed before launch), **[Nice]** (nice to have),
**[Optional]**. Items already known are ✅; items still needed are ⬜.

> The website is built to launch with graceful "details coming soon" placeholders, so you
> can go live with the **[Required]** items and fill the rest in over time.
